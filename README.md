# Cutl

Псевдо-сократитель ссылок, который на самом деле является интерактивным пранком с аудио- и визуальными эффектами.

---

## Особенности проекта

- **Маскировка:** Интерфейс имитирует работу обычного, безопасного сервиса для сокращения ссылок, у которого произошла ошибка.
- **Скрытый триггер:** При клике активируются заранее подготовленные визуальные и звуковые эффекты (воспроизведение аудиофайла).
- **Автономность:** Проект работает полностью на стороне клиента (в браузере), не требует серверной части и не собирает пользовательские данные.

---

## Стек технологий

- **HTML5** — базовая структура страницы
- **CSS3** — стилизация и ключевые кадры (keyframes) для анимации мигания
- **JavaScript** — логика перехвата действий пользователя и управления воспроизведением медиа
- **Tailwind CSS** — утилитарные классы для быстрой верстки

## Запуск локально

Проект является полностью статическим и не требует установки зависимостей (Node.js, Python и т.д.).

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Kievsky332/Cutl.git
   ```
2. Зайдите в проект
   ```bash
    cd Cutl
   ```
3. Откройте файл index.html двойным кликом в любом современном браузере.
   ---
   # Структура проекта
   ```text
    Cutl/
     ├── index.html       # Основная разметка и логика страницы
     ├── cut.png          # Изображение (иконка или элемент интерфейса)
     ├── moo.mp3          # Аудиофайл, воспроизводимый при активации триггера
     └── LICENSE          # Лицензия проекта (MIT)
   ```
